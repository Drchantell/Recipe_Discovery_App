Recipe Discovery App

This is a simple student project built with React. It lets users browse recipe categories, search meals, view details, and save favorite recipes.

Goal
Create a recipe app that uses React skills like components, state, hooks, routing, and context.

Features
- Browse categories
- View recipes in each category
- Search for recipes
- Open a recipe to see ingredients and instructions
- Save and remove favorites
- Save favorites with localStorage
- Show loading and error messages

Tools Used
- React
- Vite
- React Router
- Context API
- Custom hooks
- Fetch API

Skills Used
- useState
- useEffect
- Custom hooks
- Reusable components
- React Router
- API calls
- Local storage

How to Run
1. Open the project in VS Code.
2. Run: npm install
3. Run: npm run dev
4. Open the local link in the browser.

API
This app uses TheMealDB API.
